# Round 07 — ACL-first feasibility + collision audit

Date: 2026-08-23

## 0. Round objective

This round deliberately does **not** try to maximize the number of attractive candidates. The objective is to search aggressively across ACL 2025/2026 main papers and selected CCF A/B AI venues, then ask whether any newly found scientific object can actually compete with the surviving Round-06 queue.

Current hard policy:

- primary seed: CCF A/B AI/NLP venues only;
- ACL main/long is highest priority;
- EACL is not eligible as a primary seed;
- low paid-API dependence;
- no large new manual annotation requirement;
- open-weight local models strongly preferred;
- GPU-heavy mechanism work is welcome;
- promotion requires a strong feasibility story, not merely an interesting title.

A candidate is especially preferred when the seed already supplies:

```text
open-model phenomenon
+ public data/artifact
+ automatic/exact labels
+ high-density critical cell
+ natural paired contrast
+ an unclosed causal/mechanistic question
```

The round also applies an anti-pattern test:

> If the next step is merely “take an existing phenomenon and add a probe / SAE / activation patching plot”, do not promote unless that intervention answers a genuinely unresolved scientific distinction.

# 1. Existing survivors re-audited

## 1.1 SemTrace remains #1

Seed: ACL 2026 main, *Sense and Sensitivity: Examining the Influence of Semantic Recall on Long Context Code Understanding*.

The seed reports a severe middle-position failure for semantic execution while lexical recall is much less position-sensitive. The key reason this remains unusually healthy is that the experimental object is already controlled:

```text
same model
same synthetic program
same operation
move only relevant code position
```

The SemTrace synthetic generator also makes intermediate program states programmatically available, so a mechanism experiment can use exact internal-computation targets rather than manually annotated reasoning labels.

### Important collision found

This cannot be framed as generic:

- “how transformers track state”;
- “why lost-in-the-middle happens”;
- “whether hidden states know the answer”.

Prior work already covers transformer state tracking, finite-state / entity-binding circuits, generic long-context positional bias, and “know-but-don't-tell” style latent-answer effects.

The remaining defensible question is narrower and stronger:

> **Why does context position selectively break operational state computation while lexical access to the same code survives?**

The required critical cell remains:

```text
edge semantic = correct
middle semantic = wrong
edge lexical = correct
middle lexical = correct
```

Only if this cell is dense should we proceed to intermediate-state localization / causal patching.

Verdict: `KEEP / SURVIVAL_TOP / #1`.

---

## 1.2 MedEinst remains #2

Seed: ACL 2026 main, *MedEinst: Benchmarking the Einstellung Effect in Medical LLMs through Counterfactual Differential Diagnosis*.

The attractive distinction remains:

> when decisive counterevidence appears, is it **not encoded**, or is it encoded but **fails to update** an already stabilized diagnostic state?

This is a genuine old scientific question (Einstellung / mental set) that becomes newly testable with open-model representations and causal intervention.

The seed already provides 5,383 paired control/trap cases across 49 diseases and defines the critical Bias-Trap cell rather than requiring us to invent it.

Mandatory gate remains pair locality. If control→trap changes are diffuse or decisive evidence cannot be located without expert manual judgment, kill rather than adding controls.

Verdict: `KEEP / SURVIVAL_TOP / #2`.

---

## 1.3 In-context representation deployment remains science-top but blocked

Seed: ACL 2026 main, *Language Models Struggle to Use Representations Learned In-Context*.

The seed directly establishes a desirable representation/behavior dissociation: novel in-context semantics can be decodable in latent states while downstream deployment remains poor. The paper does not close the causal mechanism and explicitly leaves deployment mechanism/intervention as an open direction.

The natural question remains:

> **What routing/readout computation determines whether an already learned in-context representation becomes behaviorally usable?**

However, this round still did not locate a sufficiently trustworthy official reproduction package. Rebuilding the entire task generator + prompting + probe regime would make us assume too much of the prerequisite risk.

Verdict: `HOLD_FOR_ARTIFACT / SCIENCE_TOP`, not ACTIVE.

# 2. New candidate: Table DRE — structural understanding vs value referencing

Seed: ACL 2026 main, *When LLMs Read Tables Carelessly: Measuring and Reducing Data Referencing Errors*.

## 2.1 Seed phenomenon

The paper identifies **Data Referencing Errors (DREs)**: models can appear to understand table structure yet cite, copy, or omit the wrong table value in intermediate reasoning. DREs occur across tested models from 1.7B to 20B. A dedicated critic improves downstream answer accuracy and a 4B critic reaches strong DRE detection F1.

The underlying benchmark construction contains programmatic table/row/value manipulations, giving this line an important resource advantage:

- structured input;
- exact row/column/value identity;
- automatic labels;
- open-size models;
- naturally local perturbations are possible.

## 2.2 Potential next question

A useful scientific distinction would be:

> **When a model references the wrong table value despite preserving table structure, is the failure caused by row/column localization, entity–value binding, or late readout substitution?**

A strong G0 would not simply probe “where table information is”. It would require paired examples where:

```text
structure query correct
relevant row/column identifiable
final referenced value wrong
```

and then test whether the correct value is represented at the relevant token/state before the wrong value takes over.

## 2.3 Collision audit

There is substantial existing work on:

- entity binding;
- positional vs lexical binding mechanisms;
- counterfactual binding patching;
- middle-position retrieval failures.

Therefore “LLMs have binding failures” is not novel enough.

The only potentially novel object is **table-specific data referencing under intact structural understanding**. We would need to show that the DRE critical cell is not reducible to generic entity binding or generic retrieval.

## 2.4 Feasibility status

Promising:

- ACL main seed;
- exact structured labels;
- small/open models;
- likely local perturbations;
- no manual annotation fundamentally required.

Not yet cleared:

- exact official reproduction repo not yet verified in this round;
- critical-cell density on one accessible model not yet measured;
- generic entity-binding collision still significant.

Verdict: `DEEP_AUDIT / ARTIFACT_AND_COLLISION_GATE`.

Do **not** promote to ACTIVE yet.

# 3. New candidate: Context-shaped truth geometry → source choice

Seed: ACL 2026 main, *How Context Shapes Truth: Geometric Transformations of Statement-level Truth Representations in LLMs*.

## 3.1 Seed phenomenon

The paper characterizes how adding context changes residual-stream truth representations. Across four models / four datasets it reports:

- early-layer truth directions with/without context are roughly orthogonal;
- representations converge in middle layers;
- context generally increases true/false separation magnitude;
- larger models distinguish relevant/irrelevant context mainly through directional changes;
- conflict with parametric knowledge induces larger geometric changes than aligned context.

This is useful because the representation phenomenon is already reported; we would not need to manufacture the initial “truth-vector changes with context” observation.

## 3.2 Potential next question

The interesting next step is not another geometry plot. It is:

> **Do context-induced transformations of truth representations causally determine which information source controls behavior when context conflicts with parametric knowledge?**

In ideal form, use same-fact aligned/conflicting contexts and ask whether intervening on the context-induced component changes context-vs-memory choice while preserving unrelated factual judgments.

That would connect:

```text
representation transformation
→ source selection
→ behavior
```

instead of merely reporting correlation.

## 3.3 Collision audit

Knowledge-conflict and truth-vector steering are crowded. ACL 2026 itself includes work that identifies and causally intervenes on conflict-mediating attention heads in multimodal settings; other truth/knowledge representation work also performs steering.

Therefore the novelty cannot be:

> “truth vectors can be steered.”

The only viable contribution is a **source-selection causal link** specific to the context-induced transformation identified by the seed.

## 3.4 Feasibility status

Major problem: no trustworthy official reproduction repository was found in this round. The Anthology page and author page expose the paper but not a clear official code artifact.

Rebuilding truth-vector extraction, datasets, context construction and model conditions ourselves would add too much prerequisite risk for immediate promotion.

Verdict: `DEEP_AUDIT / HOLD_FOR_ARTIFACT`.

# 4. ImplicitMemBench — attractive old problem, not promoted

Seed: ACL 2026 main / Best Resource Paper, *ImplicitMemBench: Measuring Unconscious Behavioral Adaptation in Large Language Models*.

The benchmark explicitly imports classic non-declarative memory constructs:

- procedural memory;
- priming;
- classical conditioning.

It evaluates 17 models and reports substantial bottlenecks, including a large inhibition-vs-preference asymmetry.

This looks extremely aligned with “old question × LLM era” at first glance.

However, the current benchmark operationalizes **behavioral adaptation after learning/priming/interference**. It does not, by itself, provide a clean representation-level storage-vs-access dissociation. A follow-up that simply probes hidden states would risk turning a cognitive benchmark into a generic representation paper.

The suite is also only 300 items, and some constructs are heterogeneous enough that one mechanism may not explain all three.

Verdict: `WATCH / OLD_QUESTION_REFERENCE`, not promoted.

Potential future rescue requires one especially clean construct with a high-density matched behavioral dissociation and an unambiguous causal target.

# 5. Temporal Forgetting further demoted by collision

Round 06 already moved Temporal Forgetting out of ACTIVE due to cross-checkpoint representation alignment and open-ended CoT problems.

Round 07 found additional nearby work on forgetting/unlearning, including NeurIPS work modeling example-level forgetting structure and large open unlearning resources/checkpoint collections. This makes the broad “what is retained internally after forgetting?” space more crowded.

The original ACL seed remains scientifically interesting, but an immediate storage-vs-access mechanism paper would still require too many assumptions.

Verdict: `WATCH / LOWER_PRIORITY_THAN_R06`.

# 6. Other searched seeds and why they do not enter the queue

## 6.1 General instruction fine-tuning causes loss of context awareness — KILL as candidate

NeurIPS 2025 work already traces the effect through role bias / attention changes, performs head-level steering, links the failure to training examples, and proposes mitigation. ACL follow-up work isolates user/assistant role-tag bias further.

Mechanism is already substantially occupied.

Verdict: `KILL / COLLISION_REFERENCE`.

## 6.2 Personality self-report vs behavioral dissociation — KILL / WATCH only

ICML 2026 *The Personality Illusion* gives an attractive self-report/behavior dissociation with open artifacts and training-dynamics analysis.

But personality activation/steering/intervention work is already crowded in 2026, so “do hidden states contain the real personality?” is not a fresh mechanism question.

Verdict: `KILL_AS_PRIMARY / BACKGROUND_ONLY`.

## 6.3 Refinement improves fluency more than adequacy — KILL

ACL 2026 document-level translation refinement work finds general refinement mostly improves fluency with limited adequacy gains and interprets refinement as projection toward the refiner distribution.

The evaluation depends substantially on LLM judges / professional translation evaluation, and the paper already develops an explanatory account.

Verdict: `KILL / RESOURCE_AND_NOVELTY_RISK`.

## 6.4 Unlearning / latent retained knowledge — KILL for this search

NeurIPS/ACL work already shows that standard unlearning evaluation can overestimate forgetting and that correlated/implicit knowledge remains. Public frameworks provide hundreds of checkpoints and many algorithms.

However, the field is crowded, and strong evaluation often relies on judges / complex knowledge-correlation definitions. It is not a high-probability first mechanism project for this queue.

Verdict: `KILL / CROWDED`.

## 6.5 METER causal reasoning — KILL as next mechanism

The seed already conducts evidence-node saliency/information-flow analysis. Adding another hidden-state mechanism layer would not create a sufficiently distinct scientific question.

Verdict: `KILL`.

## 6.6 Instruction-vector / SAE causal semantics papers — methodology/collision only

ACL 2026 already contains papers that identify causal semantic modules, ablate/amplify them, and compose concept/relation components to create counterfactual outputs. These are useful methodological references but are not new scientific objects for the candidate pool.

Verdict: `REFERENCE_ONLY`.

# 8. Execution implications

The active queue should remain disciplined:

```text
1. SemTrace critical-cell prerequisite
2. MedEinst pair-locality + critical-cell prerequisite
3. keep hunting official artifact for in-context deployment
4. artifact/collision audit Table DRE
5. artifact/collision audit Context Shapes Truth
```

Do not write large mechanism code for #4/#5 until their gates pass.

## What would change the ranking?

### SemTrace dies if

- `edge-correct / middle-wrong / lexical-intact` is sparse on accessible open models;
- lexical and semantic failure collapse together;
- intermediate-state diagnostics reduce to generic position degradation.

### MedEinst dies if

- control→trap edits are diffuse;
- decisive evidence cannot be isolated automatically/reproducibly;
- high-density trap failures disappear on accessible open models.

### In-context deployment rises to #1/#2 if

- official code/data/generator is found;
- one accessible open model reproduces the latent-representation / failed-deployment cell without tuning.

### Table DRE rises if

- official artifact is verified;
- a high-density `structure-correct / reference-wrong` cell exists on one open 7B/8B model;
- failure survives controls against generic entity binding / retrieval.

### Context Shapes Truth rises if

- official reproduction artifact appears;
- context-induced truth geometry predicts conflict source choice within the same fact/task, not merely dataset/model averages.

# 9. Round-07 lesson

The strongest lesson from this search is that **ACL main contains many attractive gaps, but most are not follow-up topics**.

A seed becomes useful only when its next scientific question is both:

1. **conceptually distinct from the seed**, and
2. **experimentally simpler than the story needed to motivate it**.

The pool therefore remains intentionally small.

The goal is not “find more topics than Candidate 20”. The goal is to find a scientific object whose prerequisite is already real enough that the first experiment tests the question rather than tests whether the question exists.
