# 2. New top lead — When Does Test-Time Reasoning Help Context Use, and When Does It Hurt?

**Status:** `RECEIPT_NEXT / MOTHER-TOPIC DEEP AUDIT`

Not a numbered candidate yet.

## 2.1 Mother contradiction

Two strong results on Qwen3 point in opposite directions.

### A. Pure long-context retrieval: thinking hurts

The Qwen3 Technical Report reports RULER results for Qwen3-8B:

```text
non-thinking average: 89.1
thinking average:     84.4
```

The Qwen team explicitly notes that reasoning content may interfere with retrieval tasks that do not require reasoning.

Qwen3 exposes thinking/non-thinking as a switch on the same model family/checkpoint interface.

### B. Noisy multi-hop context: thinking rescues

ACL 2026 Main:

**Failure Modes in Multi-Hop QA: The Weakest Link Effect and the Recognition Bottleneck**

Official repo:

`cambridgeltl/weakest-link-effect`

The released analysis states that `Qwen3-8B-Think` matches or exceeds its gold-only baseline under the full 18-document context, despite standard instruction-following models suffering a strong recognition/position bottleneck.

The official artifact contains:

- MuSiQue / NeoQA / 2Wiki preprocessing;
- raw-result schema;
- paper-table generators;
- bootstrap/McNemar analysis;
- paper-number verification script;
- attention analyses;
- Qwen3 thinking/non-thinking experiment support.

This is not merely `thinking helps hard tasks`. The interesting object is the **sign reversal**:

```text
retrieval-like context use      -> thinking can hurt
composed/noisy evidence use     -> thinking can strongly help
```

Natural mother question:

> **What computation requirement determines whether test-time reasoning improves or degrades context utilization?**

# 3. Exact external collision audit

## 3.1 GuarantRAG is a serious near collision, but does not currently subsume the matched question

ACL 2026 Main:

**Guaranteeing Knowledge Integration with Joint Decoding for Retrieval-Augmented Generation**

Appendix C.5 explicitly compares Qwen3-14B vs Qwen3-14B-T and reports that thinking gains increase with query complexity:

```text
simple factoid:      +1.3 to +2.4 pp
moderate:            +2.4 to +3.8 pp
complex:             +3.8 to +5.4 pp
multi-hop:           +5.2 to +7.1 pp
reasoning:           +6.1 to +7.8 pp
```

Therefore the following headline is already occupied and must NOT be our claim:

> `thinking helps complex questions more than simple questions`.

However, GuarantRAG does **not** provide the matched experiment required by our mother contradiction:

- complexity bins combine different queries/datasets;
- their complexity labels mix linguistic/semantic features and manual verification;
- simple and multi-hop cases are not the same evidence instance;
- thinking is positive even in their simple bins, so they do not locate the published retrieval-vs-integration sign reversal.

Our project survives only if it studies the **boundary under matched evidence/context**, not an aggregate complexity gradient.

Therefore this cannot become:

# 4. Why MuSiQue gives a cleaner first scientific axis than cross-benchmark comparison

MuSiQue already includes `question_decomposition`.

For a 2-hop item, the data provides:

```text
final composed question
atomic subquestion 1 -> answer + supporting paragraph
atomic subquestion 2 -> answer + supporting paragraph
```

The Weakest-Link pipeline already constructs an 18-document bank with exactly two gold paragraphs and sixteen matched distractors.

Therefore the first novel experiment can hold constant:

```text
model/checkpoint
18-document context
source documents
supporting evidence
context length
position assignment
item identity
```

while changing only the computation requested:

```text
atomic evidence retrieval / local inference
vs
composed 2-hop integration
```

under:

```text
thinking on
vs
thinking off
```

This avoids the weak cross-benchmark story `RULER says X, MuSiQue says Y, therefore maybe compositionality explains it`.

The project is promoted only if the contradiction can be localized **inside one matched experimental object**.

# 5. Research Branch Map

The reason this lead is stronger than recent one-arrow candidates is that the mother contradiction remains scientifically meaningful even if one proposed boundary variable fails.

## Branch A — Boundary / characterization

Locate where the effect of thinking changes sign or magnitude:

- atomic retrieval;
- one-step inference;
- two-hop composition;
- 3–4 hop composition;
- evidence position / weakest-link visibility;
- noise level.

A failure of `hop count` as the boundary does not erase the published retrieval-vs-multi-hop contradiction; it redirects characterization toward another natural task property.

## Branch B — Computation dynamics

Once a matched sign difference exists, compare what thinking actually changes:

- evidence re-reading / reference frequency in generated reasoning;
- evidence-order verification;
- answer revision;
- attention to gold documents using the seed repo's existing attention pipeline;
- when evidence becomes answer-relevant during decoding.

No hidden-state story before the behavioral boundary exists.

## Branch C — Reasoning budget dose-response

Use a frozen small set of reasoning budgets only after the on/off interaction is established:

> Is retrieval hurt by unnecessary deliberation while integration requires a minimum computation budget?

This can reveal underthinking / useful-thinking / overthinking regimes.

## Branch D — Task topology

Weakest-Link already finds different behavior for vertical MuSiQue chains vs more horizontal NeoQA evidence structures.

Question:

> Is the value of thinking determined by the topology of evidence integration rather than nominal context length?

## Branch E — Intervention / method

Only after the scientific boundary is mapped:

- trigger thinking based on integration structure rather than generic difficulty;
- selectively allocate reasoning budget after evidence acquisition;
- separate retrieval phase from integration phase;
- train a policy that preserves direct retrieval while adding deliberation only when composition is needed.

The method is not the topic generator.

## Kill Branch A's first hypothesis

> `compositionality/hop count is not the boundary`.

## Kill the mother topic

The mother topic should be abandoned if:

1. the official Weakest-Link Qwen3 thinking/non-thinking cell cannot be reproduced;
2. the Qwen RULER negative thinking effect cannot be reproduced under the official model/evaluation contract; or
3. after both are reproduced, the apparent contradiction is explained entirely by an implementation/model-version mismatch rather than task computation.
