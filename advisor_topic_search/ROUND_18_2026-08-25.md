# Candidate 1 — When Is No Evidence Evidence?

## Mother question

**When should a missing observation count as evidence against a hypothesis, and do language models reason about the observation process that determines that evidential force?**

## External construct

A non-observation only becomes negative evidence relative to an observation model. If evidence would almost certainly have been detected under hypothesis H, failure to observe it is informative; if detectability is low, the same absence is weak evidence.

This is a classical issue in Bayesian inference, diagnosis, search, audit, forensics, and scientific reasoning.

## ACL / EMNLP / NAACL Main-scale package

A one-dimensional detectability curve would be too narrow. The full paper is one coherent study of **informative absence**:

1. **Detectability:** same null observation, vary expected detection probability.
2. **Coverage vs effort:** distinguish “searched a lot” from “had a sensitive search process.”
3. **Repeated nulls:** independent vs overlapping searches with matched count/effort.
4. **Decision consequence:** continue search vs abstain vs conclude evidence against H.

Expected abstract-level findings can include monotonicity/calibration, heuristic substitution (effort for sensitivity), double-counting of overlapping nulls, and downstream search-stopping failure.

## Collision audit

Adjacent RAG/abstention work studies evidence sufficiency, answerability, over-searching, missing evidence, and conflicting evidence. This does not directly test the key variable `P(observe evidence | H)` or whether a non-observation's epistemic value changes with the observation process.

A 2026 conceptual framework on informative absence reinforces that the construct itself is active outside LLM research; it does not occupy the LLM behavioral/method narrative.

## Unique narrative

> **Negative evidence is not a Boolean content label. Its evidential value depends on the observation process. We test whether LLMs reason about that process and whether failure explains search-agent stopping errors.**

## Method runway

**Observation-Model-Aware Search / Belief Controller**

Represent/estimate coverage, sensitivity, false-negative rate, and overlap across searches, convert a null result into a likelihood contribution, then control belief updating, stopping, abstention, or additional search.

The method directly inserts the variable identified by the science; it is not generic calibration.

## G0

Programmatic scenarios with fixed prior/content and null outcome; vary only expected detectability. First test ordinal monotonicity, then independent-vs-overlapping repeated nulls.

## Verdict

`STRONG_KEEP / MAIN_SCALE / NOVELTY_STRONG / METHOD_RUNWAY_VERY_STRONG / LOW_PREREQUISITE_TAX`

# Candidate 2 — Controls Are Tests of Assumptions

## Mother question

**Can an LLM scientific reasoner identify what assumption an experimental control probes, distinguish valid from superficially plausible controls, and update the main claim correctly when that control passes or fails?**

## External construct

Negative controls, positive controls, placebos, falsification outcomes, and control populations have evidential value because they probe specific assumptions. A control is not useful merely because it is called a control; validity depends on invariance/no-effect requirements, shared bias/confounding mechanisms, and diagnostic sensitivity.

This is a classical scientific-method / causal-inference problem independent of LLMs.

## ACL / EMNLP / NAACL Main-scale package

1. **Control selection:** choose a control for a stated threat/assumption.
2. **Control validity:** separate correct controls from ones violating no-effect, shared-bias, or sensitivity requirements.
3. **Control interpretation:** determine what pass/fail does and does not imply about the main causal claim.
4. **Control generation/transfer:** design controls for new natural-language studies/domains while targeting the same assumption.

The unified factorization is:

```text
no direct treatment effect
× shared relevant bias/confounding pathway
× sufficient sensitivity to expose the violation
```

## Collision audit

AI-scientist work such as POPPER studies automated falsification; SCOPE studies experiment-plan completeness/configuration; current scientific-reasoning benchmarks evaluate causal deduction/abduction or causal reasoning under structured noise. These are close in application but do not systematically isolate **the logic and validity conditions of controls themselves**.

ACL 2026 already accepts broad causal/scientific reasoning narratives (e.g., causal inference from real-world text and structured-noise causal reasoning), so the scope is compatible with an ACL-family Main paper rather than merely an AI-systems benchmark.

## Unique narrative

> **Existing AI-scientist work asks whether models can propose experiments or falsify hypotheses. We ask whether they understand controls as tests of specific assumptions—and whether that understanding can be made explicit in experiment-design agents.**

## Method runway

**Control-Aware Scientific Critic / Experiment Designer**

Represent:

```text
main claim
→ threatened assumption
→ control type
→ no-effect/invariance condition
→ shared bias mechanism
→ diagnostic power
```

Then reject invalid controls, propose targeted controls, interpret pass/fail conservatively, and route to sensitivity analysis/redesign when needed.

## G0

Generate small causal graphs plus NL study descriptions with exact labels: valid negative-control outcome/exposure, treatment-affected invalid control, non-shared-bias invalid control, and low-power/irrelevant control.

## Verdict

`STRONG_KEEP / MAIN_SCALE / UNIQUE_NARRATIVE_STRONG / METHOD_RUNWAY_VERY_STRONG / COLLISION_MEDIUM_BUT_DISTINCT`

# Candidate 3 — Missingness Is Data

## Mother question

**Does an LLM data analyst understand that why values are missing changes what can be validly inferred, even when the observed incomplete table is identical?**

## External construct

MCAR/MAR/MNAR and related missing-data theory concern the data-generating process, ignorability, bias, recoverability, and identifiability. Missingness is not simply a cell-filling problem.

## ACL / EMNLP / NAACL Main-scale package

1. **same observed table/mask, different missingness mechanism**;
2. **mechanism × analysis choice**: complete case, imputation, weighting, sensitivity/bounds;
3. **mechanism × target**: prediction vs descriptive parameter vs causal estimand;
4. **identifiability boundary/deployment shift**: when a point estimate is unjustified and assumptions/bounds/new data are required.

## Collision audit

Recent LLM work benchmarks missing-value imputation under MCAR/MAR/MNAR, and statistical work shows that the role of missingness differs sharply between inference and prediction. The closest LLM papers therefore occupy **imputation/prediction**, not the proposed question of **inferential validity conditional on missingness mechanism**.

## Unique narrative

> **Existing LLM missing-data work asks how well models fill missing cells. We ask whether LLM analysts understand that the mechanism producing missingness changes what analyses and conclusions are justified.**

## Method runway

**Missingness-Mechanism-Aware Analysis Controller / Identifiability Gate**

Infer/receive a missingness graph or assumptions, identify the target estimand, determine ignorability/recoverability, and route to valid analysis, sensitivity/bounds, ask-for-more-information, or abstention.

Method success is measured by valid downstream inference, not imputation RMSE.

## G0

Synthetic complete data with known truth; create matched visible tables under known missingness processes and score analysis-choice/identifiability decisions programmatically.

## Verdict

`STRONG_KEEP / MAIN_SCALE / UNIQUE_NARRATIVE_STRONG / METHOD_RUNWAY_VERY_STRONG / LOW_PREREQUISITE_TAX`

# Candidate 4 — Same Study, Different Population

## Mother question

**Given an internally valid result in a source population, can an LLM determine whether and how the result should be transported to a different target population?**

## External construct

External validity / transportability is a mature causal-inference problem. Population differences matter only when they interact with treatment effects, structural mechanisms, or support/positivity; surface demographic mismatch alone is not a sufficient reason to discount evidence.

## ACL / EMNLP / NAACL Main-scale package

1. **effect-modifier awareness:** same trial estimate, source/target differ on modifier distribution;
2. **shift type:** irrelevant covariate shift vs true effect-modifier shift vs structural/mechanism shift;
3. **support/positivity:** target subgroup absent/underrepresented in source;
4. **multi-study synthesis:** choose/combine evidence for a target-population query.

Boundary condition: transport-relevant information explicit vs inferable from study/population text vs absent and requiring abstention/new data.

## Collision audit

Classical/statistical transportability methods are mature and actively used in healthcare. LLM clinical evidence-synthesis systems increasingly extract eligibility criteria or use population-similarity weighting. The closest 2026 agentic meta-analysis work weights studies by eligibility alignment, but similarity is not equivalent to causal transportability/effect modification.

Direct searches did not identify a systematic LLM study of **transportability reasoning itself**: whether models distinguish irrelevant population mismatch from effect-modifying mismatch and know when transport is identifiable.

## Unique narrative

> **Evidence-synthesis systems mostly extract/aggregate results or measure population similarity. We ask whether language models understand the causal conditions under which evidence from one population applies to another—and build synthesis around those conditions.**

## Method runway

**Transportability-Aware Evidence Synthesis Agent**

Extract/represent target population, candidate effect modifiers, structural differences, and support; construct a lightweight selection/transport record; standardize/reweight when justified; request target data or abstain when transport is not identifiable.

## G0

Synthetic randomized studies with analytically known heterogeneous effects. Keep source estimate and overall mismatch magnitude fixed while contrasting irrelevant-covariate shift vs true effect-modifier shift.

## Verdict

`STRONG_KEEP / MAIN_SCALE / NOVELTY_STRONG / METHOD_RUNWAY_VERY_STRONG / DIRECT_LLM_COLLISION_LOW`

# Candidate 5 — Same Estimate, Different Precision

## Mother question

**When two observations have the same numerical estimate, do language models assign different evidential weight according to the precision/reliability of the measurement process?**

## External construct

Measurement theory and statistics distinguish point estimate from measurement error/precision. A value measured by a high-noise instrument does not carry the same evidential force as the same value measured precisely; reliability also interacts with replication count and heterogeneous sensors/sources.

## ACL / EMNLP / NAACL Main-scale package

A single standard-error prompt is too narrow. The Main-scale story is **measurement-model-aware evidence reasoning**:

1. **magnitude × precision:** same estimate, controlled variance/SE/reliability;
2. **replication × precision:** multiple noisy measurements vs fewer precise measurements;
3. **heterogeneous reliability:** combine sources/sensors with different error models;
4. **measurement shift/decision:** precision changes across study/deployment, or the system chooses whether replication is needed.

Expected findings can separate value sensitivity, sample-count heuristics, uncertainty accumulation, and representation-format boundaries (natural language, table, interval, sensor metadata).

## Collision audit

Current LLM measurement-error literature largely treats the **LLM itself as a noisy measurement instrument** or decomposes uncertainty in LLM evaluation pipelines. CausalGame includes measurement error as one challenge in active scientific discovery. Work on estimative uncertainty/confidence intervals evaluates LLM uncertainty expression. These are adjacent but do not systematically test the inverse question: **does an LLM reason correctly about the known reliability of external measurements when evaluating evidence?**

## Unique narrative

> **LLM reliability work asks how uncertain the model is. We ask whether the model understands uncertainty in the evidence-generating instrument itself, separating observed magnitude from measurement reliability.**

This is a clean Kisako-style interaction of two mature factors rather than a model-specific quirk.

## Method runway

**Measurement-Model-Aware Evidence Reasoner**

Attach or infer a measurement model for each observation and propagate it into evidence weighting, confidence, replication requests, and downstream decisions. Implementations can use structured reliability metadata, learned reliability-aware aggregation, or a verifier that checks whether conclusions are stable under measurement uncertainty.

## G0

Programmatically generate identical point estimates under controlled standard errors/noise models. Test ordinal evidence weighting, then a matched repeated-measure condition that separates `more observations` from `more precision`.

## Verdict

`NEW_KEEP / MAIN_SCALE / DIRECT_COLLISION_LOW / METHOD_RUNWAY_STRONG / VERY_LOW_PREREQUISITE_TAX`
