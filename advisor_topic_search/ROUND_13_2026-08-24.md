# 2. Correct interpretation

Do **not** write:

```text
MedEinst did not reproduce
```

or:

```text
encoding-vs-update hypothesis failed
```

Neither is supported.

The valid subset actually passed every substantive Bias Trap gate. The problem is that 62.5% of the frozen pairs were not validly measurable under the selected CoT output interface.

The correct statement is:

> The selected local measurement route does not provide sufficient usable support for a trustworthy mechanism experiment.

This is a Layer-C measurement/support stop, not a scientific falsification.

# 3. Why the route is archived instead of repaired again

The repository allows one principled repair when a concrete measurement defect is discovered before interpreting the scientific result.

That repair was already used.

After the repaired run still produced 62.5% invalid support, a third redesign of prompt / output contract / parser / semantic matcher would create substantial outcome-informed researcher freedom.

Therefore:

```text
one demonstrated defect
-> one frozen repair
-> persistent catastrophic invalidity
-> archive the route
```

not:

```text
repair parser
-> inspect results
-> repair prompt
-> inspect results
-> add semantic matcher
-> inspect results
-> eventually obtain a clean critical cell
```

This is the measurement analogue of the repository's `DO_NOT_TUNE` rule.

# 4. New reusable selection lesson

## Measurement support must be judged before effect strength

A strong effect on the valid subset does not compensate for catastrophic invalid support.

Topic 22 is especially useful because it could have tempted us to continue:

```text
Bias Trap count = 34
Bias Trap rate  = 37.36%
all substantive gates pass
```

But those numbers are conditional on an interface that failed for most frozen examples.

For future candidates, require:

1. enough valid support before reading the interesting effect;
2. explicit separation of `generation failed`, `measurement failed`, and `scientific behavior absent`;
3. no more than one principled measurement repair unless genuinely new external evidence changes the measurement object.
