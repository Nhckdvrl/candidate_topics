# 2. Correction: external collision was being used too aggressively

The previous audit sometimes treated the existence of neighboring 2025–2026 work as if it were itself a kill condition.

That is wrong for a crowded field.

The correct test is:

> **After granting the strongest neighboring papers, is there still enough independent scientific narrative for an ACL / EMNLP / NAACL paper?**

A candidate survives normal overlap when it still owns a distinct:

- title-level question;
- decisive experimental contrast;
- main conclusion;
- behavioral boundary/characterization;
- mechanism or causal analysis;
- intervention/training implication;
- generalization story.

Kill for collision only when the closest work has already occupied most of those components and the remainder is basically another model/dataset/probe/control.

Detailed rule: `COLLISION_AND_INTERNAL_HISTORY_POLICY.md`.

# 5. Internal reconciliation: Topic 05 constrains future storage-vs-access ideas

`Temporal Forgetting — storage loss vs access loss` had been retained in the advisor WATCH list as if it were merely an attractive untested direction.

But numbered Topic 05 already tested one identification route and archived it for conceptual failure.

The problem was not simply that one probe failed. Prefix rescue changes the task:

```text
P(solve | x) != P(solve | x + correct prefix)
```

Therefore rescue cannot distinguish retained uncued skill from:

- task simplification;
- reduced search space;
- supplied intermediate variables;
- conditional continuation;
- generic guidability.

The broad storage-vs-access question remains scientifically valid. But any future revisit must bring a **genuinely new identification strategy** and explicitly explain why Topic 05's failure no longer applies.

Status in Active is now:

`INTERNAL_COLLISION / TOPIC_05_ARCHIVED / NEW_IDENTIFICATION_REQUIRED`.

# 9. Main lesson from this reconciliation

Two distinct principles must coexist:

> **Do not demand zero collision from the literature. Demand enough remaining ACL/EMNLP/NAACL narrative.**

and

> **Do not ignore our own negative evidence. A topic we actually ran and stopped is not merely another neighboring paper; it is a constraint on future search.**

The search process should be aggressive about finding new paper-sized stories, but conservative about forgetting experiments we already paid to run.
