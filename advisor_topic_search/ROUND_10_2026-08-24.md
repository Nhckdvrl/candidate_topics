# 2. SCIENCE TOP — Does Knowledge Arbitration Have a Training History?

## Working title

**Does Knowledge Arbitration Have a Training History?**

Alternative scientific framing:

**Path Dependence in the Development of Parametric-vs-Context Knowledge Use**

## 2.1 Seed

ACL 2026 Main:

**How Training Data Shapes the Use of Parametric and In-Context Knowledge in Language Models** — Minsung Kim, Dong-Kyum Kim, Jea Kwon, Nakyeong Yang, Kyomin Jung, Meeyoung Cha.

The seed asks what data statistics make a model learn to balance parametric knowledge (PK) and in-context knowledge (ICK). Its controlled synthetic experiments show a counterintuitive result: robust confidence-dependent arbitration emerges only when three data properties co-occur — intra-document repetition, moderate inconsistency, and a skewed knowledge distribution. The paper also traces the development of PK/ICK use during training and checks analogous dynamics in real Pythia/OLMo pretraining, then studies post-training effects.

The seed therefore already owns:

- `what static corpus properties support balanced PK/ICK use?`;
- the basic PKU/ICKU development curves;
- the fact that post-training can reshape arbitration.

Do **not** repackage any of those as our novelty.

## 2.2 One-step new question

The missing old-learning-science question is **path dependence**:

> **If two models receive exactly the same training examples with exactly the same final empirical distribution, can different histories of when reliable vs conflicting evidence appears leave them with persistently different knowledge-arbitration policies?**

This is not generic `data order matters`.

The scientific object is whether the development of a specific learned policy — when to trust parametric memory versus current context — exhibits hysteresis / blocking / history dependence.

A minimal contrast can keep fixed:

```text
same initialization distribution
same model architecture
same total tokens
same exact multiset of documents
same final repetition rate
same final inconsistency rate
same final entity-frequency distribution
```

and change only the temporal organization:

```text
A: reliable-context phase -> mixed/inconsistent phase
B: mixed/inconsistent phase -> reliable-context phase
C: fully interleaved control with the identical multiset
```

The primary endpoint is the **final arbitration curve after all conditions have consumed the identical dataset**, not transient training loss.

## 2.3 Why the positive result would matter

If final arbitration differs after identical evidence totals, then a model's eventual source-use policy is not determined only by the corpus distribution summarized at the end of training.

Early experience would create a persistent learning history.

That changes how to interpret data-mixture recipes: two corpora with the same aggregate statistics need not create the same model behavior if their schedules differ.

If no persistent difference survives once the complete multiset has been consumed, the null is also informative: the striking seed phenomenon is primarily distribution-driven rather than history-dependent.

## 2.4 Research Branch Map

### Branch A — Behavioral boundary / hysteresis

- Does an order effect survive after the final data multiset is identical?
- How large a phase is required before history matters?
- Does the effect wash out with additional identical training?
- Is there asymmetry between `reliable -> inconsistent` and `inconsistent -> reliable` histories?

### Branch B — Development / critical window

- At what training stage can changing the data regime still reverse the arbitration policy?
- Is there an early window after which the policy becomes resistant to later evidence?

This branch is checkpoint-based and does not require hidden-state interpretation.

### Branch C — Mechanism / representation

Only after A/B stand:

- do histories converge behaviorally but retain different internal organizations?
- or does a persistent behavioral hysteresis correspond to stable differences in source-selection computation?

Use bounded checkpoint comparisons / causal interventions; do not begin with a generic probe sweep.

### Branch D — Intervention / training

- interleaving schedules that erase harmful history dependence;
- replay schedules that reopen plasticity;
- curriculum schedules that deliberately create stable but calibrated arbitration.

### Branch E — external generalization

Only after the controlled object is established:

- continual pretraining;
- domain adaptation;
- post-training after pretraining;
- updated or conflicting factual corpora.

## 2.5 What kills one branch vs the mother object?

A particular `critical window` hypothesis can fail while a persistent final order effect remains.

The mother object is killed if, under a frozen matched-data design:

```text
final arbitration(A) ~= final arbitration(B) ~= final arbitration(interleaved)
```

within a preregistered practically meaningful bound, and the null is replicated on the seed's supported controlled settings.

Do not rescue by changing model size, schedule shape, or selecting a special entity subset after seeing the null.

## 2.6 Collision audit

Near work exists on:

- generic curriculum / data ordering for pretraining and SFT;
- training-order effects in unlearning;
- broad path-dependence discussions;
- data-organization methods for training efficiency.

The audit did **not** find a 2025–2026 paper directly holding the training multiset/final distribution fixed while testing persistent history dependence of **parametric-vs-context knowledge arbitration**.

This exact scientific object currently survives.

## 2.7 Artifact / resource audit

Strengths:

- ACL Main seed;
- small controlled transformer setting in the seed;
- automatic synthetic labels;
- no paid API or human annotation prerequisite;
- GPU-rich local environment is suitable for repeated controlled training;
- mother branches are not reasoning-centric.

Blocking problem:

The paper/public author pages point to the work, but no trustworthy accessible official GitHub reproduction repository was located in this audit. A cited repository spelling was also not resolvable through GitHub.

Under `REPRODUCTION_RECEIPT_POLICY.md`, this is not `CODE_NEXT`.

**Status:** `SCIENCE_TOP / #1 NON-REASONING / HOLD_FOR_OFFICIAL_ARTIFACT`.

Do not register a numbered topic until the exact seed training/evaluation contract is reproducible from an official artifact.

# 3. SCIENCE HOLD — Is Apparently Unlearned Structured Knowledge Actually Cue-Bound?

## Working title

**Did the Model Fail to Store the Fact—or Are We Asking in the Wrong Form?**

Scientific framing:

**Encoding Specificity of Parametric Knowledge Acquired from Structured Data**

## 3.1 Seed

ACL 2026 Findings:

**SParK-Eval: Evaluating Structure-Aware Knowledge Acquisition in LLMs for Domain Adaptation to Industrial Records**.

The seed reports that domain-adaptive pretraining acquires substantially more knowledge from natural sentences than from structurally non-standard inputs such as tables and entity lists. Normalizing inputs into natural sentences improves acquisition.

## 3.2 One-step new question

The seed evaluates whether knowledge can later be elicited through its QA evaluation interface.

A classic memory distinction remains:

> **When a fact trained in a table/list fails a natural-language QA probe, is the fact absent from parametric memory, or is retrieval cue-dependent on the structure in which it was encoded?**

This is a storage-vs-access question motivated by encoding specificity, not `try another prompt until it works`.

A clean experiment would train the **same facts** under matched formats and then cross the encoding and retrieval formats:

```text
                 RETRIEVAL CUE
ENCODING      sentence   table-like   list-like
sentence         ?           ?           ?
table            ?           ?           ?
list             ?           ?           ?
```

The critical result is an interaction: apparently lost structured facts recover preferentially under encoding-matched cues.

## 3.3 Research Branch Map

- A: behavioral encoding-specificity matrix across structures;
- B: development — when format-bound memory becomes format-invariant during DAPT;
- C: mechanism — shared factual content vs format-specific access paths;
- D: intervention — mixed-format replay / normalization for format-invariant storage;
- E: external domains — tables, lists, JSON-like records, industrial logs.

## 3.4 Collision audit

This candidate has meaningful near collisions:

1. EMNLP 2024 Findings explicitly invokes encoding specificity for in-context teaching/rationale demonstrations. That is an ICL/reasoning setting, not parametric facts acquired from structured pretraining data.
2. A 2026 `Memory Retrieval in Transformers` paper studies encoding specificity for contextual attention-based retrieval and keyword cues, not this parametric-training-format question.
3. EMNLP 2025 Findings `Enhancing LLM Knowledge Learning through Generalization` shows that training the same knowledge under diverse formatting/paraphrased contexts improves later QA extraction. This is the most serious neighbor: it occupies part of the claim that format diversity improves knowledge acquisition.

Therefore novelty must be specifically **storage failure vs encoding-matched access for already trained structured facts**, not `format matters` or `format augmentation helps`.

## 3.5 Artifact / venue audit

Problems:

- seed is ACL Findings rather than ACL Main;
- no trustworthy complete official reproduction package was verified;
- the 2025 formatting-generalization paper compresses the available novelty space.

**Status:** `SCIENCE_HOLD / #2 / VENUE+ARTIFACT+COLLISION_GATE`.

Do not register.

# 4. Audited but rejected this round

## 4.1 SMI / factual-retention upper bound -> semantic interference

ACL 2026 Main `Beyond Scaling: Measuring and Predicting the Upper Bound of Knowledge Retention in Language Model Pre-Training` has an unusually complete public artifact and shows factual recall is strongly predictable from frequency, specificity and model size.

A tempting next question was whether residual retention depends on the number/similarity of competing facts.

**Killed by collision:** CoNLL 2024 already directly studies the LLM fan effect and reports that recall uncertainty is modulated by association fan, including fan induced by pretraining data. 2026 cognitive-memory work further connects semantic similarity to fan-style interference.

Verdict: `KILL AS NEW TOPIC / KEEP AS RESOURCE`.

## 4.2 Incomplete Learning after SFT

ACL 2026 provides a striking phenomenon: even after SFT convergence, models fail to reproduce some supervised training examples.

But the seed itself already decomposes the phenomenon into several causes and tests targeted mitigations.

Verdict: `SEED CONSUMES TOO MUCH SCIENTIFIC SPACE`.

## 4.3 Multilingual factual acquisition / shared concept development

There are strong checkpoint-rich papers tracing factual acquisition and shared concept spaces during pretraining.

They are useful references for experimental design, but they make multilingual/language structure the scientific object. They are not promoted in the current advisor-facing search, whose priority is broader learning/memory/representation phenomena.

Verdict: `REFERENCE / NOT CURRENT TARGET`.

## 4.4 Generic continual-learning forgetting

Many strong ACL/NAACL/EMNLP works already study catastrophic forgetting, replay schedules, curriculum, and multi-stage adaptation.

A new candidate must expose a more specific contradiction than `new learning causes old knowledge loss`.

Verdict: `CROWDED / DO NOT GENERATE FROM GAP MATRIX`.

# 6. What changed in the search process

The most important lesson of this round is not `we found two more topics`.

It is that the advisor-facing search target has changed from:

```text
interesting LLM failure
-> one mechanistic explanation
```

to:

```text
classic learning / memory distinction
+ externally anchored LLM phenomenon
+ accessible training/checkpoint handle
-> reproduced mother object
-> multiple independent branches
```

And advisor fit is now applied **before** investing in a fashionable topic.

A scientifically strong reasoning object can be rejected simply because it is the wrong lab-scale bet.

Likewise, an artifact-complete topic can be killed if its scientific question is already occupied (SMI -> fan effect).
