# 1. FINALIST #1 — Cue Competition / Kamin Blocking in LLM In-Context Associative Learning

**Status:** `TOP_POOL / NEW / G0_DIRECT / LOW_PREREQUISITE`

## 1.1 Seed

NeurIPS 2025 Main, *Large Language Models as Model Organisms for Human Associative Learning*.

The seed establishes that in-context LLM behavior can be used as a controlled associative-learning model organism and studies representational integration/differentiation across six models. It does **not** test classical Kamin blocking / cue competition.

Classical learning question: is association formation driven merely by repeated co-occurrence, or does an already predictive cue reduce learning about a redundant new cue?

## 1.2 Mother question

> **When two cues co-occur with the same outcome equally often, does an already-established predictor block an LLM from learning the new cue–outcome association?**

Equivalent sharper form:

> **Is LLM in-context association count-based, or prediction-error / informativeness-sensitive?**

This is a real learning-theory question before mentioning hidden states, probes, or LLM internals.

## 1.3 One-clean-contrast G0

Classic forward-blocking schedule:

```text
BLOCKING
Phase 1: A -> X repeated
Phase 2: A+B -> X repeated
Test:    B -> ?

MATCHED CONTROL
Phase 1: C -> Y or neutral matched exposure
Phase 2: A+B -> X repeated
Test:    B -> ?
```

Critical control:

```text
B-X co-occurrence count is identical.
Only prior predictive history of A differs.
```

Primary effect:

```text
P(X | B, blocking) < P(X | B, matched control)
```

Use synthetic nonce cues/outcomes and multiple counterbalanced mappings. No annotation, no external API, no seed reproduction prerequisite.

## 1.4 Why the result would matter

If blocking appears despite identical B-X co-occurrence, simple exposure-count explanations are insufficient. If blocking does not appear across a clean powered panel, that is also informative: LLM ICL associative behavior may differ from a central signature used to constrain human/animal associative-learning theories.

## 1.5 Full-paper runway

Only after G0 survives:

1. **Unblocking:** change the compound outcome so prediction error returns; does learning about B recover?
2. **Overshadowing:** manipulate relative cue salience without Phase-1 prior learning.
3. **Acquisition vs performance:** test whether B-X information is absent, retained but behaviorally suppressed, or recoverable under changed test conditions.
4. **Representational trajectory:** ask where B-X association changes relative to the already predictive A-X relation.
5. **Causal intervention:** perturb the incumbent A predictor / prediction-error-like state and test whether B acquisition changes.
6. **Cross-model generalization:** Qwen / Llama / Gemma families and scale.

The paper story is not “we found blocking in LLMs.” It is a controlled answer to whether modern in-context associative learning is governed by **mere co-occurrence versus cue competition / prediction error**.

## 1.6 Collision audit

Searches included:

- `Kamin blocking large language models`
- `blocking effect LLM associative learning`
- `cue competition LLM associative learning`
- `unblocking large language model in-context learning`
- `prediction error in-context associative learning`

No direct LLM paper testing the classic blocking/unblocking object was found in this audit. Nearby work studies associative representational plasticity, vocabulary interference, generic ICL interference, or classical blocking in humans/animals.

### Important internal-history distinction

This is **not** a revival of the previously failed latent-inhibition topic.

```text
latent inhibition:
pre-expose target cue B without outcome, then learn B -> X

blocking:
learn A -> X first, then learn compound A+B -> X, test B
```

The scientific manipulation and predicted learning principle are different.

## 1.7 Kill lines

Kill / demote if:

- a direct 2025–2026 LLM blocking/unblocking paper is found;
- effect exists only for one prompt wording / one tokenization / one selected model;
- matched B-X exposure cannot be maintained exactly;
- effect disappears under nonce-label and mapping counterbalancing;
- a positive requires searching many schedules / strengths / prompt formats.

# 2. FINALIST #2 — Information Non-Monotonicity under Progressive Truthful Clues

**Status:** `TOP_POOL / ARTIFACT_FIRST / VERY_CHEAP_G0`

## 2.1 Seed / artifact

EMNLP 2024 Main, *Do great minds think alike? Investigating Human-AI Complementarity in Question Answering with CAIMIRA*.

The released ProtoBowl / QuizBowl artifact contains progressive questions where clues accumulate over time. Public Hugging Face artifacts expose approximately:

- `3.82k` progressive questions;
- `304k` agent-response rows.

The original paper uses these trajectories to study human–AI proficiency/complementarity, not the monotonicity question below.

## 2.2 Mother question

> **If every new clue is truthful and relevant to the same answer, can receiving strictly more information make an LLM abandon a correct answer for a wrong one?**

Call the phenomenon **information non-monotonicity** or **truthful-evidence reversal**.

This is not generic “more context hurts.” The clean event is:

```text
same question
same agent
clues 1..t      -> correct
clues 1..t+1    -> wrong
new clue         = truthful evidence for the same gold answer
```

## 2.3 One-clean-contrast G0

First shot uses **released response trajectories only**; no model generation is required.

For each question × agent trajectory, measure adjacent transitions:

```text
wrong -> wrong
wrong -> correct
correct -> correct
correct -> wrong   <-- critical event
```

Primary quantities:

- correct→wrong reversal rate;
- reversal rate conditional on being correct at t;
- symmetric wrong→correct recovery rate;
- persistence: whether the answer returns to correct at t+2;
- concentration by agent family / question.

Hard first gate: the critical cell must be dense enough that the phenomenon is not a few scoring/parsing accidents.

## 2.4 Why the result would matter

Normatively, additional truthful evidence about the same target should narrow the hypothesis space. A systematic `correct -> wrong` transition therefore exposes a clean failure of evidence accumulation rather than missing knowledge.

A negative is also informative: progressive factual QA may be behaviorally monotone even when generic long-context benchmarks are not.

## 2.5 Full-paper runway

If G0 is dense:

1. **Competitor introduction:** does the new clue mention a feature/entity strongly associated with a plausible wrong answer?
2. **Specificity / ambiguity:** are reversals caused by broad clues, highly specific clues, or semantic category switches?
3. **Order intervention:** permute only clue order while keeping the clue multiset fixed; test path dependence.
4. **Matched open-model rerun:** reproduce a frozen set on local Qwen/Llama/Gemma models.
5. **Boundary mechanism:** at the exact correct→wrong step, test whether the previously correct answer representation vanishes or remains present but loses readout control.
6. **Causal rescue:** patch/steer only after the behavioral transition object is frozen.

This gives a natural bridge from an artifact-only screen to controlled evidence integration and then mechanism.

## 2.6 Collision audit

Searches included:

- `correct to wrong Quiz Bowl LLM clues`
- `answer reversal Quiz Bowl language model`
- `progressive clues LLM answer switching`
- `information monotonicity language models QA`
- `truthful evidence answer reversal LLM`

Nearby literature shows broadly that more context/evidence can hurt, but this audit found no direct paper whose main object is the **adjacent correct→wrong transition under monotonically accumulating truthful QuizBowl clues**.

## 2.7 Kill lines

Kill / demote if:

- released rows cannot be reliably ordered into same-agent clue trajectories;
- score changes are dominated by answer canonicalization differences;
- correct→wrong transitions are extremely sparse;
- reversals vanish after exact-answer alias normalization;
- the effect reduces entirely to one bad clue or corrupted question rather than a systematic evidence-integration phenomenon.

# 3. FINALIST #3 — Positional Imprinting of Parametric Knowledge

**Status:** `TOP_EXECUTABLE / ARTIFACT_VERIFIED / RECEIPT_PENDING`

This is retained from the previous active pool after a fresh Round-08 collision audit.

## 3.1 Seed

NAACL 2025 Main / Oral, *Where is the answer? An empirical study of positional bias for parametric knowledge extraction in language model*.

The seed establishes a strong training-document positional effect: facts appearing later in a document are harder to extract through closed-book QA after training.

## 3.2 Mother question

> **If facts ultimately receive identical position exposure counts and identical later washout training, does the position at which a fact was first acquired leave a persistent imprint on final parametric accessibility?**

The key distinction is:

```text
current / cumulative position statistics
vs
historical acquisition path
```

## 3.3 One-clean-contrast G0

Within the same model run, counterbalance facts into two groups:

```text
Group E: initially learned in early position
Group L: initially learned in late position
```

Then equalize later exposure so both groups receive the same total early/late position counts and identical optimizer/LR trajectory.

After a common washout phase, test closed-book factual access.

Primary contrast:

```text
final QA(Group E) - final QA(Group L)
```

The comparison should be within-model and fact-level, not between two independent training runs if avoidable.

## 3.4 Why it remains distinct

The seed asks whether **where information occurs in the training document** affects extraction and links the effect to autoregressive training. The proposed mother question asks whether **the historical position of first acquisition remains causally relevant after final exposure statistics have been equalized**.

This is a learning-history / hysteresis question, not a restatement of positional bias.

## 3.5 Full-paper runway

If imprinting survives:

- washout law / reversibility;
- sensitive period: how many early exposures create the imprint?;
- delayed equalization vs immediate interleaving;
- replay/interleaving intervention;
- storage vs access diagnostics only after the behavioral effect stands;
- internal traces of early vs late acquisition;
- cross-model / fact-domain generalization.

## 3.6 Collision audit

Fresh searches included:

- `positional imprinting parametric knowledge LLM`
- `training position parametric knowledge acquisition order`
- `first exposure training position language model knowledge`
- `initial position fact training language model knowledge extraction`
- `same exposure positional bias training facts`

The audit recovered the NAACL seed and generic exposure/data-mixing work but did not find a direct study of **first-acquisition position with later position exposure equalized**.

## 3.7 Resource gate

The official `omron-sinicx/WhereIsTheAnswer` artifact has already been verified in prior rounds. Keep the existing receipt-first discipline before registration.

## 3.8 Kill lines

Kill / demote if:

- the exact upstream seed relation fails on the selected executable setup;
- fact-level counterbalancing is confounded with optimizer trajectory or document identity;
- equalization itself erases the seed effect before the mother contrast becomes measurable;
- effect survives only because cumulative token context / frequency differs.

# 4. Important Round-08 demotions / kills

## 4.1 OAKS historical-state intrusion — DEMOTED after fresh collision

Original attractive question:

> For evolving facts `A -> B -> C -> D`, when the model is wrong at D, does it intrude C (recency), A (primacy), the most frequent old value, or a semantically similar old value?

OAKS itself is an excellent ACL 2026 continual-stream artifact and reports update delay, distraction, and multiple fact changes.

However, the 2026 preprint *Transformers Remember First, Forget Last: Dual-Process Interference in LLMs* (arXiv:2603.00270; first submitted 2026-02-27) directly compares proactive and retroactive interference across 39 LLMs and reports active **primacy intrusion** in proactive-interference errors.

Combined with other 2025–2026 proactive-interference/context-management work, the historical-state-intrusion mother question is no longer clean enough.

**Verdict:** `COLLISION_RISK / DEMOTED / DO_NOT_PROMOTE`.

## 4.2 SMI contextual diversity vs repetition frequency — KILL

Scientific question was attractive:

> At fixed fact frequency, does contextual/source diversity matter more than repeated exposure in similar documents?

Two blockers:

1. official SMI processing does not provide the desired context-diversity statistic directly; rebuilding it requires large corpus-side processing over The Pile / ROOTS / SlimPajama-scale sources;
2. 2025 work such as *Facts in Stats* already directly manipulates contextual diversity in synthetic pretraining and studies its learning consequences.

**Verdict:** `KILL / COLLISION + PREREQUISITE TAX`.

## 4.3 Belief consistency vs rigidity — HOLD, not finalist

ACL 2026 reports an appealing dissociation: code/math continued-pretraining families can become more belief-consistent while suffering more logical failures.

Natural question:

> Does training make a model more consistent, or merely more rigid?

Not promoted because:

- the clean causal attribution currently relies too much on model-family comparisons;
- nearby 2025–2026 work already studies stubbornness/deference under challenge;
- no single low-tax mother experiment was found that forces the distinction without rebuilding a new benchmark.

**Verdict:** `WATCH / HOLD`.

## 4.4 ImplicitMemBench inhibition-vs-preference asymmetry — HOLD

ACL 2026 ImplicitMemBench provides a useful classical-conditioning resource and reports a striking inhibition/preference asymmetry.

Not promoted because:

- current ACTIVE file already flags construct-validity concerns;
- promoting it alongside blocking would over-concentrate the final pool in the same implicit/associative-memory family;
- blocking has a cleaner old-theory contrast and cleaner G0.

**Verdict:** `WATCH / INSPIRATION_ONLY`.

## 4.5 Generic storage-vs-access after SFT / temporal forgetting — DO NOT REOPEN

This area has become even more crowded in 2026. ACL 2026 directly studies temporal forgetting during training, and fresh August 2026 work studies factual access failures after SFT where recognition/ranking can survive while open generation fails.

This also conflicts with the repository's own Topic-05 identification history.

**Verdict:** `DO_NOT_REOPEN`.
