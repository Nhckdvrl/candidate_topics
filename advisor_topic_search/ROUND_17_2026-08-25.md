# Candidate 1 — When Is No Evidence Evidence?

## Mother question

**When should a missing observation count as evidence against a hypothesis, and do language models use the expected detectability of evidence when making that judgment?**

## Why the problem exists independently of LLMs

The meaning of a non-observation depends on an observation model. If hypothesis `H` were true and the evidence would almost certainly have been observed, not observing it is strong evidence against `H`. If detection was unlikely, the same absence is weak evidence.

This is a mature question in Bayesian reasoning, cognitive science, forensics, diagnosis, search, and scientific inference. Human work such as Hsu et al., *When Absence of Evidence Is Evidence of Absence*, explicitly studies inference from absent data as a function of how expected / detectable the missing event should have been.

## ACL / EMNLP / NAACL Main-scale package

`MAIN_SCALE`

The paper is **not** one curve of `P(detect | H) -> confidence`. A coherent Main-scale narrative contains four linked questions:

1. **Detectability calibration** — under content-matched null observations, does belief update track expected detection probability?
2. **Factor decomposition** — detectability vs raw search effort vs stated coverage vs false-negative rate vs prior probability.
3. **Accumulation and dependence** — do multiple failed searches combine correctly when their coverage is independent vs overlapping?
4. **Agent decision consequence** — when should a search/research agent continue searching, abstain, or upgrade `not found` to evidence against a hypothesis?

These are four manipulations of the same external construct: the observation process that gives absence evidential meaning.

## Unique novelty package

### Closest collisions

- search-augmented LLM work studies over-searching, answerability, abstention, and the presence of negative evidence;
- evidence-sufficiency work studies whether currently available evidence is enough;
- retrieval-based verification work distinguishes support/refutation/insufficient evidence.

### Why the narrative remains ours

> **Existing work largely treats negative evidence as a retrieved content category or tests whether evidence is sufficient. This topic asks whether the model represents the observation process that determines how much a *non-observation itself* should count as evidence.**

The novelty is not “LLMs sometimes over-search.” It is **observation-model-sensitive negative evidence reasoning**.

### Expected headline findings

A strong abstract could support 3–4 findings such as:

1. belief updates are monotone / non-monotone in expected detectability under otherwise matched absence;
2. models substitute search effort or document count for actual sensitivity/coverage;
3. overlapping failed searches are incorrectly double-counted as independent negative evidence;
4. the same miscalibration predicts premature stopping or wasteful continued search in tool-using agents.

## Method runway

### Method family

**Observation-Model-Aware Search and Belief Controller**

Maintain explicit estimates of:

```text
coverage / sensitivity / false-negative rate
→ P(observe evidence | H=true)
→ likelihood contribution of a null result
→ belief update + continue/stop/abstain decision
```

### Why method follows from finding

If the failure is specifically that LMs ignore expected detectability, the remedy is to represent and accumulate the missing observation-process variable. This is not generic confidence calibration.

### Method success criterion

- calibrated belief update against known generative ground truth;
- fewer unjustified `not found -> false` conclusions;
- fewer wasteful searches after cumulative independent detection probability is already high;
- more continued search when absence remains uninformative.

## First-shot G0

Programmatically generate hypotheses and null observations with fixed content/prior while varying only `P(detect evidence | H=true)`.

Primary test:

```text
higher expected detectability
→ stronger negative belief update
```

First test ordinal monotonicity, not exact numerical calibration.

## Verdict

`STRONG_KEEP / MAIN_SCALE / NOVELTY_STRONG / METHOD_RUNWAY_VERY_STRONG / LOW_PREREQUISITE_TAX`

# Candidate 2 — Same Evidence, Different Sampling Process

## Mother question

**Do language models condition inductive generalization on why observed examples were selected, or do they treat evidence only as a bag of observed examples?**

## External construct

Identical observed examples can rationally have different evidential meaning under different sampling mechanisms. Classical cognitive work distinguishes strong/property sampling from weak/category/random sampling. Human studies also show that sampling frames can be supplied after evidence, retracted, and replaced, causing reinterpretation of already-seen data.

## Main-scale package

`MAIN_SCALE`

A full paper should unify:

1. **same exemplars, different selection policy** — strong vs weak sampling;
2. **timing** — sampling frame before vs after evidence;
3. **belief revision** — retract and replace an initially wrong sampling frame;
4. **ICL / retrieval transfer** — curated demonstrations, random samples, nearest-neighbor retrieval, diversity-based retrieval, and adversarial selection all induce different evidence-generation policies.

A particularly strong Kisako-style interaction is:

```text
example diversity × sampling assumption
```

because diversity should not carry the same evidential meaning under every sampling process.

## Unique novelty package

### Closest collisions

ICL has a large demonstration-selection literature: retrieval, diversity, influence, learned selectors, example ordering, and active selection. Generic LLM property-induction work also exists.

### Unique narrative

> **Existing ICL work asks which examples should be selected. We ask whether the *selection policy itself is part of the evidence* once the examples are observed.**

This distinction is the core narrative and is wide enough for a Main paper without depending on one model-specific anomaly.

### Expected headline findings

1. identical examples yield different generalization only when models correctly use the sampling process;
2. models may use a frame when stated before evidence but fail to reinterpret old evidence when the frame arrives later;
3. retraction/replacement reveals whether sampling assumptions behave like revisable beliefs or sticky prompt context;
4. retrieval-selected ICL can be systematically miscalibrated when the reasoner treats selected demonstrations as if they were random samples.

## Method runway

### Method family

**Selection-Aware ICL / Sampling-Process-Aware Demonstration Reasoning**

Reason over:

```text
P(example | hypothesis, selection policy)
```

rather than only example contents.

Possible implementation families:

- retriever emits inclusion-probability / policy metadata;
- selector estimates sampling propensities;
- demonstrations are reweighted by selection likelihood;
- latent sampling policy is inferred when the selection mechanism is unknown.

### Method success criterion

- calibrated generalization under content-matched policy changes;
- robustness across curated / random / retrieval / diversity / adversarial selectors;
- improved transfer when the selector changes at deployment time.

## First-shot G0

Use a programmatic one-dimensional concept space with analytically distinct strong- and weak-sampling posteriors. Keep observed exemplars identical; change only the sampling story/process.

## Verdict

`STRONG_KEEP / MAIN_SCALE / UNIQUE_NARRATIVE_STRONG / METHOD_RUNWAY_STRONG / LOW_PREREQUISITE_TAX`

# Candidate 3 — Controls Are Tests of Assumptions

## Working title

**Controls Are Tests of Assumptions: Do Language Models Understand What Experimental Controls Actually Validate?**

## Mother question

**Can an LLM scientific reasoner determine what assumption a control experiment tests, whether a proposed control is actually valid, and how passing or failing that control should change confidence in the main result?**

## External construct

Negative controls, placebo tests, positive controls, falsification outcomes, and control populations are not generic “extra experiments.” Their evidential value comes from which assumption they probe and from specific validity conditions.

For example, a negative-control outcome must be unaffected by treatment while sharing the relevant confounding/bias mechanism with the focal outcome. A placebo test is informative only if it is more likely to fail under the relevant assumption violation than when the assumption holds.

This is a mature scientific-method / causal-inference construct independent of LLMs.

## Fresh collision audit

Adjacent work includes:

- POPPER / automated sequential falsification: agents generate experiments that challenge hypotheses;
- SCOPE-style autonomous experimental-design benchmarks: planning completeness, configurations, datasets, baselines, metrics;
- work on LLM-simulated experiments that itself uses negative-control outcomes to diagnose synthetic-user drift.

These do **not** systematically ask whether the model understands the **logic and validity conditions of controls themselves**.

## ACL / EMNLP / NAACL Main-scale package

`MAIN_SCALE`

A coherent paper has four linked tests:

1. **Control selection** — choose a valid negative/positive/placebo control for a stated causal threat;
2. **Control validity** — distinguish surface-plausible controls from controls that satisfy the necessary causal conditions;
3. **Control interpretation** — understand what a pass/fail result does and does not imply about the main design;
4. **Control generation/transfer** — design controls for unseen study descriptions and domains while targeting the same causal assumption.

The crucial factor decomposition is:

```text
control has no treatment effect
×
control shares the relevant bias/confounding mechanism
×
control has enough sensitivity/power to detect the violation
```

A control can fail by violating any one of these conditions.

## Unique novelty package

### Novelty one-liner

> **Current AI-scientist work evaluates whether models can propose experiments or falsify hypotheses; we test whether they understand the semantic/causal role of controls as probes of specific research-design assumptions.**

This is not generic experimental-design quality.

### Expected headline findings

1. models can name standard controls but often select controls that do not share the relevant confounding pathway;
2. models may treat “no effect in placebo” as proof of the main causal claim, revealing a specific inferential error;
3. validity decomposes differently across negative-control outcome, negative-control exposure, placebo-treatment, and placebo-population tests;
4. failures on control logic predict unreliable autonomous experimental design even when high-level plans look complete.

## Method runway

### Method family

**Control-Aware Scientific Critic / Experiment Designer**

Represent each proposed control by:

```text
main causal claim
→ threatened assumption
→ control type
→ invariance/no-effect requirement
→ shared bias mechanism
→ expected diagnostic power
```

The system can then:

- reject invalid controls;
- propose assumption-targeted controls;
- interpret pass/fail results conservatively;
- recommend sensitivity analysis or redesign when a control fails.

### Why method follows from science

If models fail because they match “control-looking” surface patterns without reasoning about the assumption being tested, the method should explicitly bind controls to assumptions and causal structure.

### Method success criterion

- higher valid-control selection accuracy;
- fewer false validations from weak/irrelevant controls;
- correct belief updates after pass/fail results;
- better experiment plans on SCOPE-like or real paper-derived tasks without merely adding more experiments.

## First-shot G0

Programmatically generate small causal graphs and natural-language study descriptions. For each, create:

- one valid negative-control outcome/exposure;
- one invalid control due to a treatment effect;
- one invalid control due to missing shared confounding;
- one weak/uninformative control.

The first scientific question is classification/interpretation under exact graph-derived labels—not full agentic experiment generation.

## Verdict

`NEW_STRONG_KEEP / MAIN_SCALE / UNIQUE_NARRATIVE_STRONG / METHOD_RUNWAY_VERY_STRONG / COLLISION_MEDIUM_BUT_DISTINCT`

# Candidate 4 — Missingness Is Data

## Working title

**Missingness Is Data: Do Language Models Reason About Why Values Are Missing Before Drawing Conclusions?**

Alternative:

**Same Observed Table, Different Missingness Process: What Can an LLM Data Analyst Validly Infer?**

## Mother question

**Does an LLM data analyst understand that the process producing missing values changes which analyses, estimands, and conclusions are valid—even when the visible incomplete table is identical?**

## External construct

MCAR / MAR / MNAR are assumptions about the missing-data-generating process, not just imputation categories. They determine when missingness is ignorable, when complete-case analysis is biased, when imputation is justified, and when a target quantity may be only partially identifiable without additional assumptions.

## Fresh collision audit

Recent LLM work studies:

- missingness patterns affecting zero-shot prediction;
- LLM missing-value imputation under MCAR/MAR/MNAR;
- time-series imputation;
- data-cleaning systems that classify/handle missingness.

The strongest adjacent work still primarily asks **prediction/imputation behavior under missingness**.

## Unique narrative

> **Existing LLM missing-data work asks how well models fill missing cells or predict with missing inputs. We ask whether LLM analysts understand that the missingness mechanism changes what can be validly inferred and what analysis should be performed.**

This is an inference/identifiability question, not an imputation benchmark.

## Main-scale package

`MAIN_SCALE`

1. **same visible table, different data-generating missingness process**;
2. **mechanism × analysis choice** — complete case, imputation, weighting, sensitivity/bounds;
3. **mechanism × estimand** — prediction vs descriptive parameter vs causal effect;
4. **identifiability boundary** — when the correct action is not a point estimate but an assumption statement, bound, sensitivity analysis, or request for additional data.

## Expected headline findings

1. whether models distinguish MCAR/MAR/MNAR as inferential assumptions rather than vocabulary labels;
2. whether the same missing mask receives different valid analysis choices under different causal stories;
3. whether models overproduce precise estimates in non-identifiable MNAR cases;
4. whether explicit missingness graphs or mechanism-aware tools repair the specific failure.

## Method runway

### Method family

**Missingness-Mechanism-Aware Data Analysis Agent**

Pipeline:

```text
infer / receive missingness assumptions or m-graph
→ identify target estimand
→ determine ignorability / recoverability / identifiability
→ choose analysis family
→ report sensitivity / bounds / assumptions when needed
```

### Success criterion

- valid analysis choice across MCAR/MAR/MNAR;
- fewer unjustified point estimates;
- correct use of sensitivity/bounding when identification fails;
- improved downstream statistical conclusions, not merely lower imputation error.

## First-shot G0

Use fully synthetic complete data with known truth; apply matched missingness mechanisms to create conditions with known valid/invalid analysis strategies and known identifiability status. No human labels required.

## Verdict

`STRONG_KEEP / MAIN_SCALE / NOVELTY_MEDIUM_STRONG / METHOD_RUNWAY_VERY_STRONG / LOW_ANNOTATION_COST`

# Candidate 5 — Same Study, Different Population

## Working title

**Same Study, Different Population: Do Language Models Reason About External Validity and Transportability?**

Alternative:

**Who Does This Evidence Apply To? Transportability-Aware Scientific Reasoning with Language Models**

## Mother question

**Given a valid study in a source population, can an LLM determine whether—and how—the result should be transported to a different target population?**

## External construct

External validity / transportability is a mature causal-inference and clinical-research problem. A treatment effect can be internally valid in the study population yet fail to transfer when source and target populations differ in effect modifiers, causal mechanisms, support/positivity, or relevant context.

This question exists independently of LLMs and is central to evidence-based decision making.

## Fresh collision audit

Adjacent work includes:

- NAACL 2024 work bringing clinical-research principles of internal/external validity into NLP model generalization;
- LLM systems for clinical-trial extraction and evidence synthesis;
- eligibility-aware meta-analysis agents that weight trials by target-population compatibility;
- classical statistical/causal transportability methods and selection diagrams.

Direct search did **not** find a systematic LLM study asking whether the model itself reasons about **transportability conditions and effect modifiers when applying study evidence to a target population**.

The closest LLM evidence-synthesis systems mostly use eligibility similarity or extraction pipelines; similarity is not the same as causal transportability.

## ACL / EMNLP / NAACL Main-scale package

`MAIN_SCALE`

A unified paper can test:

1. **effect-modifier awareness** — same trial result, source/target differ on modifier distributions;
2. **shift type** — irrelevant covariate shift vs true effect-modifier shift vs structural/mechanism shift;
3. **positivity/support** — target subgroup absent or weakly represented in source evidence;
4. **multi-study synthesis** — combine studies with different populations to answer a specific target-population query.

A strong boundary-condition axis is whether the information required for transport is:

```text
explicitly stated
vs inferable from eligibility/population descriptions
vs absent and requiring abstention / new data
```

## Unique novelty package

### Novelty one-liner

> **Current LLM evidence-synthesis work largely extracts and aggregates study results or scores population similarity; we test whether language models understand the causal conditions under which evidence from one population applies to another, and build transportability-aware synthesis around those conditions.**

This is not generic domain generalization of the model itself.

### Expected headline findings

1. models may correctly notice demographic mismatch yet fail to distinguish irrelevant population differences from true effect-modifier shifts;
2. similarity heuristics can overweight studies that are close in surface demographics but non-transportable for the target estimand;
3. models may over-extrapolate when target support/positivity is missing;
4. explicit transportability structure can improve target-specific synthesis and calibrated abstention.

## Method runway

### Method family

**Transportability-Aware Evidence Synthesis Agent**

Core representation:

```text
source study
+ target population
+ effect modifiers / structural differences
+ support / positivity
→ transportability judgment / formula / reweighting / abstention
```

Possible method components:

- extract candidate effect modifiers from study text;
- build a lightweight selection diagram or structured transportability record;
- distinguish similarity features from effect-modifying variables;
- reweight/standardize when transportable;
- request target data or refuse extrapolation when not identifiable.

### Method success criterion

- better target-population effect estimates in synthetic ground-truth settings;
- correct identification of non-transportable cases;
- improved target-specific evidence synthesis over eligibility-similarity weighting;
- calibrated abstention when key effect modifiers or support are missing.

## First-shot G0

Use synthetic randomized studies with analytically known heterogeneous treatment effects. Keep source study estimate fixed while manipulating source/target population composition and whether the shifted covariate is an effect modifier.

Primary contrast:

```text
same population mismatch magnitude
but
irrelevant covariate shift vs effect-modifier shift
```

A model that reasons only by surface similarity will treat them similarly; a transportability-aware reasoner should not.

## Verdict

`NEW_STRONG_KEEP / MAIN_SCALE / NOVELTY_STRONG / METHOD_RUNWAY_VERY_STRONG / DIRECT_LLM_COLLISION_LOW`

# Demoted / killed after this round

## The Same Fit Is Not the Same Evidence — DEMOTE

Still scientifically valid, but the 2026 landscape around LLM p-hacking, preregistration, workflow logging, and adaptive evaluation makes the narrative visibly more crowded. A distinct “epistemic appraisal of selection history” story survives, but it is no longer stronger than Experimental Control Logic or Transportability.

Status: `WATCH / replacement candidate only`.

## Agreement Is Not Corroboration — KILL FOR NOW

Recent work on false majorities, latent shared sources, provenance-aware memory arbitration, and provenance-aware aggregation occupies too much of both the mother story and obvious method.

A narrower “implicit lineage inference” version could survive, but that would violate the no-narrowing-for-novelty rule.

Status: `KILL / do not promote`.

## Cue Competition / Kamin Blocking — KILL

The external construct is strong, but recent LLM work already imports Rescorla–Wagner-style learning dynamics into mixed-context LLM analysis. A blocking/unblocking-only paper would now be too narrow unless it expanded into a much larger learning-rule project, raising prerequisite cost and collision risk.

Status: `KILL`.
