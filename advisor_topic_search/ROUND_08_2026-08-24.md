# 1. PRE-REGISTRATION TOP — Does Repetition Make an LLM Trust the Claim, or the Source?

## 1.1 ACL seed

**ACL 2026 main/long**: *Whose Facts Win? LLM Source Preferences under Knowledge Conflicts* — Schuster, Gautam, Markert.

Official paper:

- ACL Anthology: `2026.acl-long.1357`

Official artifact:

- repository: `JaSchuste/llm-source-preference`
- audited repository commit: `87dd466f10a76ea1cadc21a552d423d2d60c0cce`
- released dataset: `JaSchuste/llm-source-preference`

The paper evaluates **13 open-weight instruction models** from Qwen2.5, OLMo-2, Llama 3 and Gemma 3 families.

The experimental design is unusually attractive for our current failure history:

- synthetic fictional facts remove parametric-knowledge contamination;
- synthetic sources remove identity/political-source contamination;
- both A/B orders are evaluated;
- the measurement is **deterministic next-token A/B probability**, not free-form generation;
- source preference is defined relative to an unattributed control for the same conflict;
- no judge model, no semantic parser, no CoT truncation.

The official inference code performs ordinary HuggingFace inference with `do_sample=False`, one generated token, and extracts the logits of `A/B`.

This is exactly the sort of measurement surface we should prefer after recent generation/parser failures.

## 1.2 Seed phenomenon is already stronger than “repetition bias exists”

The paper first establishes a strong source hierarchy: models generally prefer institutionally corroborated sources such as government/newspapers over people/social-media sources.

Then it separates three conditions around a low-credibility social-media side against government:

```text
1-table majority:
  two distinct social sources represented together

2-table majority:
  two distinct social sources represented as two tables

repetition:
  exactly the SAME social source / same information appears twice
```

The reported average preference shifts are approximately:

```text
1-table true majority     :  6.17
2-table true majority     : 33.90
same-source repetition    : 30.04
```

Thus the huge effect is not simply rational counting of two independent corroborating sources. Repeating the same information from the same source nearly matches the effect of a two-table majority.

The paper further shows that even **repeated unattributed information** can reverse the original preference for attributed information.

So the seed has already removed one major alternative explanation for us:

> “The model merely treats two independent sources as stronger evidence.”

That is not enough to explain the same-source repetition result.

## 1.3 External old-science anchor

A 2025/2026 human social-cognition paper by Mattavelli, Brambilla & Unkelbach, *Repeating Statements Increases Source Credibility*, gives a much sharper next question.

Across four preregistered human experiments, repetition increased not only perceived truth of a statement but also perceived credibility of its source.

The crucial Experiment 2 asks whether the credibility change **transfers to a novel statement from the same source**. It does: sources previously associated with repeated statements are trusted more on new statements.

This gives a clean old scientific distinction for LLMs:

```text
claim-local repetition / fluency
vs
source-level credibility update
```

That distinction is more natural and more consequential than “which layer contains repetition bias?”.

## 1.4 Proposed big question

> **When repetition overrides a model's source-credibility hierarchy, does repetition increase support only for the repeated claim, or does it change how the model treats the source itself?**

Short paper-title form:

> **Does Repetition Make an LLM Trust the Claim—or the Source?**

This is potentially a much larger result than another RAG-bias observation.

### If source-level transfer exists

Then repeated misinformation from one low-credibility source does something worse than making one duplicated claim look strong:

> it can make the model trust **new, unrelated information from that source**.

This implies source-reputation contamination / induced trust and matters for RAG, multi-document QA, agent memory and repeated misinformation.

### If source-level transfer does not exist

Then the ACL repetition vulnerability is more claim-local: familiarity / duplicate-evidence weighting raises the repeated proposition but does not update source trust.

This is a scientifically interpretable null because it directly separates two theories.

# 2. Why this is currently safer than the recently attempted objects

## 2.1 No competence gamble

The task is binary source conflict. A model does not need to solve long code execution, long CoT, medicine, or a difficult external benchmark before the phenomenon can be measured.

## 2.2 No generation/parser gamble

The official setup measures deterministic A/B token probabilities. There is no answer extraction, reasoning completion, semantic judge or long-horizon generation.

## 2.3 The exact confound the new experiment varies is simple

The target test claim can be held **identical** across treatment/control.

Only the earlier exposure changes:

```text
TREATMENT:
  source S was previously associated with repeated claim X

CONTROL:
  the same amount/content exposure occurred,
  but repetition was associated with a matched other source S'

TEST:
  novel claim Y from source S conflicts with government information
```

The test-stage prompt is identical. Claim Y was never repeated.

A preference shift toward S on Y therefore cannot be the ordinary repeated-target-claim effect.

## 2.4 Automatic measurement

Primary outcome can reuse source preference / answer-token probability. No human annotation is required.

## 2.5 Small open model already used in the seed

Gemma-3-4B is one of the paper's 13 models and is also the teacher/base model used in the mitigation experiment.

The final ACL paper gives exact Gemma-3-4B teacher reference values in Section 6 / Figure 11:

```text
Government vs No Source:
  original source preference ≈ 29.6
  repetition gap            ≈ 45.9

Government vs Social Media:
  original government preference ≈ 3.4
  repetition gap                 ≈ 33.2
```

The paper's final fine-tuned values are different from older arXiv-version headline numbers, so **the ACL final PDF is authoritative for the receipt**.

# 4. New behavioral G0 only after receipt

## Question

> Does repetition attached to a source transfer to the model's treatment of a **new claim from that same source**?

## Minimal matched design

For each synthetic source identity `S` and matched source `S'`:

### Treatment history

```text
S: claim X
S: claim X          # duplicate
```

### Matched control history

```text
S': claim X
S': claim X         # same repetition/content budget, wrong source identity
```

### Test — identical across both histories

```text
Government: claim Y = A
S:          claim Y = B

Which value is correct? A / B
```

where `Y` is a different entity/attribute/claim from `X` and was never shown in the history.

Counterbalance:

- A/B answer order;
- table order;
- which fictional source receives treatment;
- claim X / claim Y pairing.

The key outcome is the within-item change in probability assigned to source `S`'s novel claim Y.

## Strongest valid positive statement

> **Prior repetition associated with a source increases that source's influence on an unrelated new knowledge conflict.**

Do not call this “credibility representation” yet. Behavioral G0 shows **source-level transfer**, not its internal mechanism.

## Primary alternative explanation to keep in mind

Repeated source-name tokens could create source-identity familiarity rather than a genuine credibility update.

This is not a reason to front-load five controls before G0. If source transfer exists strongly, one later matched control can distinguish mere source-name exposure from repetition-of-claims-by-source.

If the G0 itself is small or unstable, stop rather than building a control tree.

# 5. Mechanism opening if source transfer passes

Only then is internal analysis justified.

The scientific distinction becomes:

```text
claim-local fluency / evidence weighting
vs
source-level learned trust state
vs
late conflict-arbitration bias
```

A useful causal experiment can keep the **test conflict exactly identical** and change only the prior history.

Possible bounded route:

1. locate a small predeclared source-token/readout site set;
2. compare repeated-source history vs matched-other-source history;
3. use natural-history activation patching into the identical target test;
4. ask whether the novel-claim preference transfers with the history-induced state;
5. verify that any intervention changes source influence without overwriting the final A/B answer token directly.

A generic source-identity probe is insufficient.

## Method opening

If source-level contamination exists, the mitigation target is broader than duplicate-document removal:

- source-reputation calibration;
- dependence-aware evidence aggregation;
- history-insensitive credibility priors;
- provenance-aware duplicate discounting.

# 6. Collision audit

The ACL seed itself studies:

- source hierarchy;
- same-claim repetition;
- majority versus duplicate repetition;
- prompting and fine-tuning to restore repetition invariance.

It does **not** test whether repetition associated with one source changes the model's treatment of a **novel claim from that source**.

The human literature directly motivates that transfer question, but is not an LLM collision.

Search also found work on:

- generic illusory-truth effects in LLM-simulated participants;
- generic knowledge conflict / RAG source reliability;
- duplicate evidence and document redundancy;
- source-aware retrieval and trust estimation.

No exact work was found that tests the claim-local vs source-level transfer distinction under matched LLM source conflicts.

Important framing boundary:

> Do not sell this as “LLMs have repetition bias” or “duplicate RAG passages are bad.” Those are already known. The paper-scale question is **whether repetition updates source-level trust and generalizes to new claims**.
