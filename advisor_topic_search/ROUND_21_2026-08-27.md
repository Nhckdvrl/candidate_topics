## Topic29 validation strategy

Public AMI conversion artifacts were inspected before code was written. The documented schema includes ordered dialogue acts plus abstractive `decisions` and summlink links to supporting utterances. The first preflight therefore counts independently annotated decision objects and multi-turn/temporally extended support chains before any model generation.

Implemented:

- deterministic conservative decision-state parser;
- source->summary state-drift scorer;
- AMI artifact-support audit;
- frozen support gates;
- unit tests and preflight runner.

The public-artifact support gates pass. A repaired temporal-prefix G0 also passes: Qwen2.5-7B-Instruct upgraded 39/52 explicitly non-final, content-grounded prefixes to unconditional decisions under a neutral prompt, versus 0/52 with a matched state-preservation instruction.

## Topic30 validation strategy

Public LexDeMod artifacts were inspected before code was written. The released classification CSV exposes clause IDs, text, a seven-way deontic label vector, and gold spans. This serves as a measurement anchor independent of simplification outcomes.

Implemented:

- conservative deontic/condition/exception parser;
- LexDeMod support receipt;
- aligned simplification-pair eligibility/drift audit;
- frozen support gates;
- unit tests and preflight runner.

The public-data support questions pass on LexDeMod and Lex-Simple. A repaired held-out gold-span G0 supplies 222 clean operator contrasts; 97.75% still receive MiniLM cosine >=0.95. The regex baseline remains candidate triage, not a natural-outcome labeler.
