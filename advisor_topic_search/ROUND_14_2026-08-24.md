## What Round 13 got wrong

Round 13 applied a useful anti-tuning instinct too mechanically:

> one principled repair still invalid -> archive measurement route

That rule ignores whether the second run has **localized a new defect that can be repaired without changing the scientific experiment**.

## Revised measurement-repair rule

A later repair is allowed after an invalid run only when all hold:

1. the new failure mode is explicitly localized by diagnostics;
2. the repair does not change the model behavior being evaluated;
3. model, sample, seed, treatment, scientific thresholds and primary estimand stay frozen;
4. the repair has no access to outcome/ground-truth information that would let it preferentially improve the desired hypothesis;
5. the repair is frozen before reading its resulting scientific metrics;
6. there is a hard support gate after the repair;
7. another failure does not trigger an open-ended search over parsers/prompts/models/orders.

Topic 22 v3 satisfies this contract.


It never receives:

```text

```

Further guards:

- explicit `0` abstention;
- two deterministic label orders;
- accept only order-invariant agreement;
- 49/49 canonical-label self-mapping preflight;
- fallback only for outputs unresolved by the old scorer;
- already-resolved predictions cannot be rewritten;
- source v2 records are SHA-256 audited;
- scientific G0b thresholds remain exactly unchanged.

`run_g0.sh` now refuses to regenerate v2 CoT implicitly. If the original records are unavailable, the v3 scoring repair cannot be silently substituted with a fresh stochastic generation run.

## Process lesson

The correct anti-fishing principle is not `one repair maximum`.

It is:

> **Do not repeatedly modify the scientific experiment after seeing outcomes. A measurement interface may be repaired when diagnostics expose a narrower defect and the repair can be made outcome-blind while preserving the original model outputs.**

This distinction prevents both bad extremes:

- tuning a scorer until the hypothesis wins;
- throwing away a scientifically promising object because a clearly separable evaluation interface was imperfect.
