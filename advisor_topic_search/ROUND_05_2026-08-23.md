# Advisor Topic Search — Round 05 (2026-08-23)

## Objective: stop confusing “runnable in principle” with “experimentally alive”

Round 05 continues the feasibility-first correction from Round 04.

The key rule is now even stricter:

> **Before promoting a mechanism topic, the exact critical cell must survive under the same prompt / same model / same computation regime that the mechanism analysis will explain.**

A seed paper may report a large `probe > behavior` gap, but if the probe and behavior were measured under different prompts, different task interfaces, or different model variants, that aggregate gap is not yet the mechanism object.

This round therefore does not add many new topics. It pushes the best surviving candidates toward actual KEEP/KILL experiments.

# 2. Numeracy — static artifact audit: PASS

Seed:

> Fengting Yuchi, Li Du, Jason Eisner. **LLMs Know More About Numbers than They Can Say.** EACL 2026 Short / Oral.

Official code:

> https://github.com/VCY019/Numeracy-Probing

## 2.1 Published model regime is excellent for us

The seed reports the gap directly on accessible 7B–8B open models.

Most importantly:

```text
Qwen3-8B
verbalization = 70.00%
classification probe = 98.88%

DeepSeek-R1-Distill-Qwen-7B
verbalization = 64.19%
classification probe = 97.38%
```

Therefore we are not assuming a closed-model phenomenon will transfer to a local model.

## 2.2 But the headline gap is NOT yet our mechanism object

A closer paper audit found an important mismatch:

```text
verbalization: one-shot prompt
probing: zero-shot prompt
```

The seed also shows prompt-position effects in several 7B–8B models and explicitly studies few-shot prompting.

Therefore the published `70.00 vs 98.88` number must **not** be interpreted as direct evidence that the same computation contains a correct ranking state that generation fails to use.

This is exactly the kind of subtle identification error that previously killed projects after code was already written.

The strengthened question is now:

> **Under the exact same balanced five-shot prompt, can Qwen3-8B's final input state linearly encode the correct ranking while that same prompt's greedy generation is wrong?**

If no, kill the access-bottleneck project.

## 2.3 Prompt-bias audit changes the G0

The seed's appendix reports that:

- one-shot demonstrations can induce answer-position imitation in some 7B models;
- increasing demonstrations improves performance and substantially reduces several positional effects;
- performance largely plateaus around five demonstrations;
- nevertheless, 7B–8B models remain very weak when the numbers are close, especially around `|log2(a/b)| < 0.1`.

Therefore we deliberately choose the official **balanced five-shot** prompt for G0 rather than exploiting the weaker one-shot regime.

This makes the project harder to pass but much more meaningful if it does.

## 3.1 Scientific-notation rounding does not corrupt the published labels

Scientific strings are formatted to five significant digits.

Across the published seed-0 datasets:

```text
int-sci displayed ties: 0
int-sci ordering changes after formatting: 0

dec-sci displayed ties: 0
dec-sci ordering changes after formatting: 0
```

Maximum relative formatting error:

```text
int-sci: 4.75896e-05
dec-sci: 4.94584e-05
```

So the reported cross-notation errors are not explainable by accidental label flips introduced by display rounding.

## 3.2 Test answer position is balanced

Published test split:

```text
int-sci: P(correct answer is A) = 0.495625
dec-sci: P(correct answer is A) = 0.496875
```

Thus the full test set is not structurally biased toward one answer position.

## 3.3 The hard regime is not a tiny cherry-picked tail

Frozen hard regime inherited from the seed:

```text
|log2(a/b)| < 0.1
```

Published test counts:

```text
int-sci: 129 / 1600 = 8.0625%
  answer-A rate = 46.51%

dec-sci: 137 / 1600 = 8.5625%
  answer-A rate = 44.53%

pooled hard test = 266 items
```

This is large enough to demand a real instance-level critical cell rather than interpreting a handful of failures.

## 3.4 Generator edge case discovered before confirmation

The released `int-sci` generator explicitly rejects `a == b`.

The released `dec-sci` generator does **not**.

The published `seed=0` happens to contain no ties, so the original experiment is clean. But when seeds 1–9 were audited, several generated occasional exact equalities after construction.

Therefore any future independent confirmation set must add:

```python
if a == b:
    continue
```

before formatting.

Do not silently reuse another random seed from the upstream generator.

If five-shot prompting closes the gap, or the same-prompt probe loses the seed's strong ranking signal, archive/downgrade the access project.

This is intentionally much stricter than reproducing Table 1.

## Implementation audit

The first implementation caught and fixed two engineering risks before server handoff:

1. tokenizer uses **left padding**, so the final prompt token is always position `-1`; `attention_mask.sum()-1` would incorrectly index padded batches;
2. with `device_map=auto`, hidden states can reside on different GPUs, so cross-device fancy indexing is avoided by taking `layer[:, -1, :]` directly.

Smoke-test mode also cannot emit project-level GO/KILL; any run with `--train-limit`, `--val-limit`, or `--test-limit` returns:

```text
SMOKE_ONLY_NO_PROJECT_DECISION
```

Only the full frozen run is allowed to decide survival.

## New feasibility concern from direct dataset inspection

The dataset description says discriminative evidence is minimally altered, but visible paired examples are heterogeneous.

Some are very local, such as replacing a small number of decisive respiratory symptoms while preserving most of the case.

Others visibly change multiple symptom statements and look closer to a broader narrative counterfactual.

Therefore this project is **not yet allowed** to assume a token-local intervention unit.

The existing script:

```text
advisor_topic_search/g0/medeinst_pair_structure.py
```

must be run over all 5,383 pairs before mechanism design.

Required outputs:

```text
changed-token fraction
sequence-match ratio
number of changed blocks
maximum changed span
most diffuse 200 pairs
```

If a large fraction of the benchmark requires diffuse rewrites, a clean token/path-patching story weakens sharply even though the behavioral Einstellung paper remains valid.

Status:

```text
WAIT_FULL_PAIR_LOCALITY_G0
```

# 9. New reusable lesson

Add this to future topic audits:

> **A representation–behavior dissociation must be measured under the same experimental condition before it becomes a mechanism object.**

Bad inference:

```text
probe under prompt A = 99%
behavior under prompt B = 70%
therefore prompt-B computation knows the answer but cannot use it
```

Valid prerequisite:

```text
same model
same prompt
same instances
same decision point
probe says correct
behavior says wrong
```

Only then ask whether the readable state is causally used.

This is an important extension of the repository's existing rule:

```text
aggregate signal != distributed mechanism
```

It should prevent another class of attractive but non-identifying mechanism projects.
