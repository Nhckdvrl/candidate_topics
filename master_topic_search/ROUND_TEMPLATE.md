# Candidate / anomaly 1

## Observed phenomenon / external anchor

What is already known to happen? Use exact systems, tasks and effect sizes where possible.

Classify evidence strength:

`Tier S / Tier A / Tier B / Tier C / Tier D`.

If the proposed central relation is only an attractive bridge between known facts, say so explicitly.

## Why it is surprising

What expectation does it violate?

## Positive-result headline

Assume the cleanest positive result. Write the one-sentence paper headline.

If the headline sounds like a small correlation, timing shift, or another variable predicting another variable, downgrade before coding.

## Why the field should care

What scientific or practical belief changes?

## Method opening — mandatory

If the positive result is true:

```text
Immediate lever exposed:
Plausible method family:
Primary failure the method would improve:
```

"Study the mechanism further" is not a method opening.

Also audit whether the obvious method family is already crowded.

## Existing explanations

What explanations already appear in the literature?

## Exact open question

One sentence.

## Cheapest decisive contrast

Describe the first experiment only. Avoid mechanism work unless required by the question.

Prefer:

```text
same object
same task / data / state
one meaningful factor changed
one primary observable
```

## Failure-pattern audit

Which archived failure is this candidate most at risk of repeating?

Check explicitly for:

- cross-paper empty-cell speculation;
- representation → behavior bridge without behavioral support;
- motivating phenomenon ≠ explanatory axis;
- two stable profiles ≠ fine-grained mapping;
- non-identifying intervention;
- prerequisite phenomenon absent;
- sparse common support / crossover;
- toy-only meaningful-regime failure;
- complexity smell.

## Meaningful-regime check

Is there already a competent, reproducible, non-toy experimental object?

## Collision audit

Search separately:

1. has the scientific question already been answered?
2. is the natural method opening already crowded?

Do not preserve novelty by narrowing to one dataset / model / prompt / layer.

## Excitement test

Finish:

> **If this is true, the exciting thing is that ________.**

If the blank is weak, kill or reframe.

## "Then what?" test

Finish:

> **If this is true, the first thing we would try to improve is ________, by ________.**

If this cannot be answered naturally, downgrade.

## Verdict

`STRONG_KEEP` / `KEEP_REFRAME` / `CHEAP_G0_ONLY` / `HOLD_FOR_EXTERNAL_EVIDENCE` / `KILL`.
